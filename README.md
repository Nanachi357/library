# Library

Library is a Spring Boot REST API project for managing books, authors, readers, and their relationships.

Implemented functionality:

- CRUD endpoints for books, authors, and readers.
- Pagination and sorting for collection endpoints.
- Book-to-author and book-to-reader relationships.
- Request validation, DTO mapping, and centralized error handling.

Main technologies: Java 21, Spring Boot, Spring Data JPA, PostgreSQL, MapStruct, Lombok, Gradle, and Docker Compose.
